# Evals

Each case checks behavioral invariants rather than exact wording. A passing agent should make the expected methodological moves and avoid disallowed shortcuts.

Use `cases.jsonl` for automated or manual regression. Add observed failures as new cases before editing the core prompt so changes remain testable.


`audit_cases.jsonl` contains regression cases for already-built products:
commercial audit, failure taxonomy, sales readiness, growth prioritization and
post-fix readiness changes.
