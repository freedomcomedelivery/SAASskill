# GTM selection & experiment economics

## Course routing baseline
1. If people actively search for the product/solution → search traffic or relevant software/store marketplace first.
2. If not searched:
   - addressable avatars < ~10,000 → outreach is a course heuristic;
   - broader audience → media traffic (Meta/Telegram/etc.).
3. Content is a low-cash/high-effort media alternative.
4. Product Hunt is additive; treat as primary only when target audience is actually there.

Do not interpret thresholds as laws.

## Economics
Build LTV estimate, target CAC, CPC/CPM forecast, channel funnel, required test budget. Course template aims for CAC materially below LTV and uses channel-specific benchmark funnels to estimate test size.

## Gate
One primary channel, one geo, sufficient budget for a meaningful test, current platform compliance check, landing ready.
