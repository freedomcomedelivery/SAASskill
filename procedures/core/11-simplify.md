# Simplify before launch

Trigger if any of the following appears without a strong reason:
- multiple primary competitors/references;
- multiple avatars;
- multiple pains;
- multiple primary benefits;
- multiple GTMs in parallel;
- several projects in parallel;
- product cannot be made/tested quickly;
- landing becomes a long multi-audience site.

Default simplification target:
`1 primary_reference + 1 avatar + 1 pain + 1 benefit + 1 GTM + 1 fast experiment`.

If simplify gate fails, do not launch merely because assets are ready.
