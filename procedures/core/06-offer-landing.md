# Offer & landing

## Landing invariant
One avatar + one acquisition channel + one CTA.

## Course structure
- strong first screen: direct product description or primary benefit; optionally avatar qualifier;
- pain/situation: concise, usually no more than one screen;
- benefits + product mechanism: the largest share; explain how value is produced and visualize/prototype it;
- offer + CTA: explicit next action and what the user receives.

Course material suggests first screen ~5% and benefits/product ~60% as teaching heuristics; preserve as `course_heuristic`, not a rigid web-design law.

## Exceptions
If market norm is a primitive/high-intent product (e.g. direct tool/search intent), let users try/use the product earlier when competitor evidence supports it.

## Technical readiness
Form works; notifications work; analytics events exist on lead/payment/key CTA; mobile/desktop matches the product/channel; landing and creative promise the same thing.
