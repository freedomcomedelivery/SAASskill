# Iteration & diagnosis

## Iteration record
period; hypothesis; implementation; plan; actual; conclusion; next_change.

## Diagnose earliest break
1. enough reach/exposure?
2. right avatar arriving?
3. clicks/engagement adequate for channel?
4. leads?
5. qualified leads?
6. explicit offer/payment ask?
7. payments?
8. economics?

Do not optimize downstream metrics while upstream sample is empty.

## Finished iteration
Needs enough time/exposure for the channel to learn and for humans to process leads. Course repeatedly warns against 1-day/very small-sample conclusions and suggests multiple iterations, up to four, before declaring failure.

## Causal discipline
Change the smallest useful set of variables per iteration.
