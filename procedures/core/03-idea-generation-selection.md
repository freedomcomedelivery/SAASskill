# Idea generation & selection

## Generation
Use market niches, reference products, avatar processes/problems and SCAMPER as idea generators. Generated ideas are semi-finished hypotheses, never validation.

## Course criteria
- existing market / not merely unique;
- ideally 3–5 close earning references;
- competitor average check;
- usage frequency;
- feasible as pet project (or with partner);
- fit with personal concept.

Course heuristic for check: roughly B2C >= $10 and B2B >= $150 is treated as attractive, but store it as `course_heuristic`, not universal truth.

## Selection
Do not collapse into weighted scoring unless user explicitly asks. Use pass/concern/blocker with evidence.

## Gate
No final selection without real references unless explicitly marked as high-risk exploratory project.
