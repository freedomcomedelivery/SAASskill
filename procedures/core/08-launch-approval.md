# Launch

1. Freeze experiment hypothesis and variables.
2. Verify current platform rules/settings.
3. Produce exact action plan: account, geo, budget, creatives/keywords, optimization event, landing, tracking.
4. Create `approval_request` with maximum spend and side effects.
5. Execute only after explicit approval.
6. Read back campaign/result identifiers; log action.
7. Do not change several variables immediately because of noisy first-day results.
