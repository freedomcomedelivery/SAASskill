# Intake & personal concept

## Goal
Get only the personal constraints that can change idea selection or launch strategy.

## Fields
Experience/skills; interesting domains; hard-no; money budget; time budget; nearest goal; reference products; optional hobbies/problems/founders; risk attitude.

## Behavior
- If user already has a project, do not force a full concept interview.
- Infer nothing sensitive or private.
- Ask only missing fields that materially affect the next decision.
- Store as `user_constraint`, not market fact.

## Gate
Pass when the agent can distinguish feasible/desirable candidates. Personal concept is helpful but not a mandatory blocker for a concrete existing project.
