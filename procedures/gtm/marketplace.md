# GTM — Marketplaces

## Validate marketplace itself
Target buyers must search there; check live competitor cards, fresh reviews/views/orders where visible, moderation rules and internal promotion options.

## Inbound
Publish a product/service card and let buyers find it. Steps: find high-performing reference cards → build direct title/hook → explain product/mechanism/benefit/offer → add credible visual/prototype → set price → use compliant internal promotion if needed.

## Outbound
Only on service/job marketplaces where responding to requests is native. Find relevant listings and send a tailored hook + mechanism + offer + CTA.

## Rule
Marketplace demand is channel evidence, not proof of the whole market.
