# GTM — Google Display / Performance Max-style media

## Use when
Broad enough audience and media discovery makes sense; not a replacement for high-intent search when search demand is obvious.

## Course notes
Start with modest budget; analyze which creative/headline/placement actually yields conversion. Later course update says audience signals/custom segments materially helped their tests.

## Current-platform gate
Verify current campaign types, PMax controls, audience signals, asset requirements and conversion setup before launch; product UI evolves.

## Diagnosis
placement quality + creative → landing → qualified conversion. Exclude poor placements only from observed evidence.
