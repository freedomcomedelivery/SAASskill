# GTM — Avito/classifieds

## Use when
Fresh listings, views/reviews and buyer searches show the service/product category is alive on the platform.

## Course structure
profile → one listing → hook/title → sales scheme → reviews/proof → launch → promotion.

`PF/behavioral factor` is discussed in the source as important to ranking. The skill must **not** manufacture fake views, fake reviews, fake accounts or other inauthentic engagement. Use only legitimate profile/listing optimization and platform-supported promotion.

## Card
2–3 hook candidates before choosing; description should cover pain, mechanism/features, benefit, offer/CTA; qualification questions; price; one sales follow-up flow.

## Experiment
Start small, collect organic/paid real reach, respond quickly, iterate hook/promotion based on legitimate funnel data.
