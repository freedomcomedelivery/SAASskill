# Artifact registry

- `personal_concept`: user-only constraints/preferences.
- `market`: definition, avatars, exclusions, green-market signals.
- `idea`: one-liner, pain, references, check/frequency/feasibility/fit.
- `competitor_record`: pricing, mechanism, audience, proof, traffic, ads, reviews.
- `research_pack`: collected evidence + source coverage.
- `marketing_contract`: geo, avatar, situation, pain, solution, product type, advantage, exclusions, price, benefit, channels.
- `landing_brief`: one avatar, one channel, one CTA, block copy and evidence.
- `economics`: LTV, target CAC, CPC/CPM, expected funnel, budget.
- `channel_plan`: channel-specific setup.
- `approval_request`: exact side effect and spend.
- `lead_record`: qualification + objections + payment outcome.
- `funnel_snapshot`: observed reach/clicks/leads/qualified/payments/spend/revenue.
- `iteration`: hypothesis → implementation → plan → actual → conclusion → next change.
