# Capability routing

Prefer capability over vendor name.

## Research
- current public facts, competitors, reviews, platform docs → web research;
- keyword/domain authority/traffic when authoritative data is connected → SEO/market data tool;
- course/source assets → Google Drive;
- code/spec persistence → GitHub/repository.

## Ads
- read campaign/account/performance through connected ads/marketing tool;
- prepare writes autonomously;
- create/pause/enable/change budget only after explicit approval and only if connector supports that write.

## Analytics / CRM
- retrieve factual funnel from connected analytics/CRM when available;
- otherwise ingest user-provided exports;
- never infer actual conversions from ad clicks.

## Fallback
If a capability is unavailable, produce a precise action package the user can execute manually; do not pretend it was applied.
