# Stage machine

| Stage | Required artifact | Primary gate |
|---|---|---|
| intake | project identity | scope understood |
| personal_concept | personal_concept | enough constraints |
| market_discovery | market candidates | market exists + evidence |
| idea_generation | idea shortlist | candidate refs found |
| idea_selection | selected idea | idea readiness |
| research_marketing | research + marketing_contract | chain coherence |
| offer_landing | landing_brief | landing readiness |
| gtm_planning | economics + channel_plan | GTM readiness |
| launch | approved action | platform + approval check |
| lead_onboarding | lead log | qualification process works |
| iteration_tracking | funnel + iteration | sufficient data |
| scale_or_pivot | decision memo | repeated evidence |

A stage may move backward when new evidence invalidates an upstream assumption.
