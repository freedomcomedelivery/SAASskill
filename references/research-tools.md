# Research sources from course materials

The course supplement lists examples such as AnswerThePublic, Semrush, Yandex Wordstat, Google Trends, Similarweb, Sensor Tower, AppMagic, AppStoreSpy, ReadReviews, Rusprofile, TGStat, Telemetr and vidIQ; competitor-ad checks include Meta Ad Library, Google Ads Transparency, TikTok Ad Library and (for CIS) Keys.so/TGStat/search inspection.

Use connected authoritative tools when available. Web/UI may change, so treat this as a source list, not a hardcoded API catalog.

For competitor revenue, course suggests public financial data where possible; when unavailable it gives a rough traffic × assumed paid-conversion × average-check estimate. Always mark this as `estimate` with assumptions.
