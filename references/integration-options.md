# Integration capabilities

## Already useful in the working environment
- Google Drive: source course assets / Docs / Sheets / Slides.
- GitHub: persist and version skill/repository artifacts.
- Web research: public competitor/market/current-platform evidence.

## Useful optional capabilities
- SEO/keyword data: Semrush/Ahrefs-like capability for demand, keywords, domains, traffic.
- Ads manager: campaign/account/performance read/write with explicit approval for writes.
- Analytics: GA/Mixpanel/Amplitude/PostHog-like event/funnel data.
- CRM: lead qualification/status/payment follow-up.

Skill should discover available tools by capability; do not hardcode one provider as mandatory.
