# Channel decision tree

```text
Does the avatar search for the solution/product?
├─ YES → Search or relevant software/store marketplace
│        └─ Check hot intent + CPC/economics + competitor presence
└─ NO
   ├─ Identifiable/narrow avatar pool (~<10k, course heuristic) → Outreach
   └─ Broad avatar pool → Media
       ├─ Meta / display
       ├─ Telegram where geo/audience fit
       └─ Content when cash budget is constrained but execution capacity exists

Additive:
- Product Hunt/Product Radar when audience/backlink/discovery value exists
- Avito/classifieds when category demand is native there
- App Store/ASA when app/store search exists
```

This tree is a starting heuristic, not a prohibition on other channels. Evidence can override it.
