# Current-platform verification

Course strategy can remain stable while buttons, campaign types, moderation and policies change.

Before any platform-specific write:
1. check current official/help documentation or live connector capabilities;
2. verify account eligibility, objective/campaign type, allowed targeting, tracking events, budget/bid constraints and moderation;
3. compare against course instruction;
4. log differences as `platform_delta`;
5. execute the current compliant equivalent preserving the methodological intent.

Do not execute course tactics that require evasion, fake engagement, fake reviews, deceptive identity, account-rule bypass or spam. Preserve them only as source context if needed to explain a difference.
