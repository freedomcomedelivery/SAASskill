# Source fidelity

- Course-derived rules keep course terminology and framing.
- Do not silently “fix” the course with generic startup advice.
- External facts, current market evidence and current platform docs are separate evidence types.
- When source has a numeric heuristic, label it as a course heuristic and record context/date if known.
- When two course materials conflict, retain both, prefer the later-dated/source-updated material for execution, and record conflict.
